# Skills

Agent skills maintained by Zac Hamann.

## Available skills

### Prompt

Create, review, and refactor prompts as clear, minimal specifications of intended behavior, generalizing corrections into principles instead of accumulating exceptions.

Install with:

```bash
npx skills add zhamann/skills --skill prompt
```

Source: [`prompt/SKILL.md`](./prompt/SKILL.md)

### Code

Write, fix, review, and refactor code as a clear, minimal expression of intended behavior, favoring governing rules over accumulated patches and speculative abstractions.

Install with:

```bash
npx skills add zhamann/skills --skill code
```

Source: [`code/SKILL.md`](./code/SKILL.md)

### Write

Write prose that is specific, direct, and natural, with a voice suited to its audience and purpose, whether drafting from scratch or revising existing text.

Install with:

```bash
npx skills add zhamann/skills --skill write
```

Source: [`write/SKILL.md`](./write/SKILL.md)

### Ship

Organize completed work into coherent commits and independent or stacked pull requests, address checks and reviews, and merge when ready.

Install with:

```bash
npx skills add zhamann/skills --skill ship
```

Source: [`ship/SKILL.md`](./ship/SKILL.md)
